
## จัดการรูปอัปโหลด

ระบบตรวจ SHA-256 ของรูปก่อนสร้างไฟล์ หากเนื้อหาเหมือนรูปเดิมจะใช้ URL เดิมและต่ออายุเวลาไฟล์ ไม่สร้างสำเนาเพิ่ม

เรียก npm run images:cleanup เพื่อดูจำนวนไฟล์ที่ไม่มีสูตรใช้งาน และ npm run images:cleanup -- --apply เพื่อลบจริง ตรวจฐานข้อมูลก่อนลบทุกไฟล์ และเว้นไฟล์ที่อัปโหลด/ใช้งานล่าสุดภายใน 24 ชั่วโมง ควรรันช่วงไม่มีผู้ใช้กำลังแก้สูตร ไฟล์ที่มีสูตรใช้งานจะไม่ถูกลบ แม้เนื้อหาซ้ำกัน

รูปใน public/uploads/recipes เข้า Git เพื่อให้ทีม pull แล้วเห็นรูปสูตรร่วมกัน ส่วน uploads ชนิดอื่นยังไม่เข้า Git เมื่อมีรูปสูตรใหม่ต้อง commit ไฟล์รูปเพิ่มด้วย การ Deploy ยังควรใช้พื้นที่เก็บรูปถาวร
