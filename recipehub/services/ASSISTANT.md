# น้องอุ่น AI

UI อยู่ใน partial assistant.ejs ซึ่ง footer เรียกใช้ ปุ่มลอยซ่อนเมื่อเปิดแชต กลับมาเมื่อปิด รองรับ Escape และมือถือ คำตอบแสดงด้วย textContent ลิงก์แนะนำสร้างจากรายการจริงที่เซิร์ฟเวอร์อนุญาต

ใส่ KKU_AI_API_KEY ใน .env และเลือก KKU_AI_MODEL (ค่าเริ่มต้น gemini-3.8-flash) แล้วรีสตาร์ตเว็บ ใช้คีย์ KKU และบัญชีต้องมีสิทธิ์/โควตาสำหรับโมเดลที่เลือก หากไม่มีคีย์ UI ยังเปิดได้แต่ไม่ส่งข้อความไปโมเดล และไม่แสดงคำตอบจำลองเป็น AI จริง

POST /api/assistant/chat รับ message และประวัติสูงสุด 8 ข้อความ GET /api/assistant/config สร้าง CSRF token ผ่าน session รองรับผู้ใช้ทั่วไปด้วย จำกัด 8 คำถามต่อ IP ต่อนาที รวม 60 คำถามต่อนาที และไม่เกิน 4 คำถามพร้อมกัน ข้อจำกัดอยู่ในหน่วยความจำ หากมีหลายเซิร์ฟเวอร์ต้องย้ายไปตัวเก็บกลาง

ส่งข้อมูลสาธารณะของสูตร/คอร์สเท่านั้น ไม่ส่งขั้นตอน วิดีโอ รายละเอียดบทเรียน ข้อมูลบัญชี หรือเนื้อหาสูตรเสียเงิน เลือกข้อมูลล่าสุดสูงสุด 200 สูตรและ 100 ต่อประเภทคอร์สก่อนจัดลำดับข้อความตรงคำถามแล้วส่งสูงสุด 30 รายการ จึงอาจไม่ได้ค้นพบรายการเก่าที่อยู่นอกชุดนี้

ข้อความของผู้ใช้และประวัติถูกส่งไป API KKU/Gemini เพื่อสร้างคำตอบ ไม่บันทึกแชตลงฐานข้อมูลของแอป การเก็บข้อมูลฝั่งผู้ให้บริการขึ้นกับนโยบายของ KKU ประวัติอยู่ใน sessionStorage ของแท็บเดิม โดยแยกตามบัญชีผู้ใช้ คืนประวัติหลังรีเฟรชหรือเปลี่ยนหน้าได้ อย่าส่งข้อมูลส่วนตัวหรือข้อมูลชำระเงิน

API: https://gen.ai.kku.ac.th/api/v1/chat/completions ใช้ Bearer key และรูปแบบ Chat Completions

ชื่อโมเดล gemini-3.8-flash เป็นค่าที่ผู้ใช้ระบุ ควรตรวจสิทธิ์และรายการโมเดลจาก KKU หากเรียกไม่ได้

เมื่อผู้ใช้เป็นเชฟ ส่งรายการแนะนำเฉพาะสูตรของตัวเองและใช้ URL /chef/recipes/:id ผู้ใช้ทั่วไปได้รับรายการสูตรและคอร์สตามปกติ
