## ระบบที่ต้องพัฒนาและสาธิต

- ระบบต้องสอดคล้องกับหัวข้อโปรเจกต์และการใช้งานจริง
- มีการเข้าสู่ระบบ โดยเอกสารระบุว่า “มีอย่างน้อย 2 ผู้ใช้งาน” ไม่ได้ระบุชัดว่าเป็น 2 บัญชีหรือ 2 บทบาท; สำหรับ CookHub ควรรองรับเชฟและผู้ใช้ทั่วไป และยืนยันการตีความกับอาจารย์หากจำเป็น
- มีการเพิ่ม ลบ แก้ไข และค้นหาข้อมูลตามผู้ใช้งาน
- Back-end ใช้ Express Framework ของ Node.js เท่านั้น
- เชื่อมต่อฐานข้อมูล MongoDB โดยใช้ Compass หรือ Atlas ตามถ้อยคำของโจทย์
- เชื่อมต่อ API อย่างน้อย 1 API ใช้จากภายนอกหรือสร้างเองได้
- Demo ด้วยเว็บแอปพลิเคชันจริง ไม่ใส่ Demo ลงใน PowerPoint
- โค้ดต้องมี comment อธิบายหน้าที่ของแต่ละ module หรือ function

- การเตรียมตัว ความพร้อม และตรงเวลา

## การใช้กับ CookHub

นี่เป็นเป้าหมายอ้างอิง ไม่ใช่การยืนยันว่าระบบผ่านแล้ว:
- ตรวจ login และสิทธิ์ของเชฟ/ผู้ใช้ทั่วไปก่อน Demo จริง; โหมดทดลองไม่ใช่หลักฐานว่า login สมบูรณ์
- ตรวจ CRUD และค้นหาสูตรอาหาร พร้อมข้อมูลที่บันทึกใน MongoDB จริง
- TheMealDB เป็น API ที่เลือกใช้ได้ ต้องตรวจการเชื่อมต่อจริงก่อนนำเสนอ
- เตรียมโครงสร้าง JSON ของ models และ API map จากโค้ดจริง
- เมื่อแก้ฟังก์ชัน ให้รักษาข้อกำหนด Express, MongoDB, API และสิทธิ์ของผู้ใช้
